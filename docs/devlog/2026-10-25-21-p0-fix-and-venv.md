## 关键技术细节

1. **`pip install -e .` 在本机失败**：pyproject 要求 `setuptools>=68`，venv 内为 `65.5.0`，加 `--no-build-isolation` 后无法升级而报错。
   Editable 安装的实际机制就是 `site-packages` 里那个 `.pth`（内容为一行 `src` 绝对路径），直接改写等价且零风险，无需网络。**今后目录迁移照此办理**。
2. **修复 venv 后立刻暴露 P0-1**：改完 pth 后第一次 `import xxt.session.login` 就报 `IndentationError`——这反证了此前所有验证都跑在旧目录代码上。
3. **为什么 43 个测试没抓到**：`login` 在 `cmd_login` / adapter 内延迟导入，`import xxt.cli` 正常；`tests/` 无 login 用例。
