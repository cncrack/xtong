## 关键决策

1. **`STATUS.md` = 当前状态唯一真相**：AGENTS.md 的"状态速览"改为指向它，避免两份状态打架（与项目一贯"只有一份真相"原则一致）
2. **一目录 = 一工具 = 一分支**：分支保护按目录生效，不按软件生效；同一目录多工具共用会让分支失效，需靠"串行 + 每次 commit"纪律
3. **main 单一写入者**：只有 `E:\xxt` 推 main；旧目录（或 worktree 派生目录）只推自己的分支，成果单向合并回 main
4. **`data/` 不双活**：真实数据只在 `E:\xxt\data`；旧目录做实验时用 `XXT_ROOT` 指向临时目录，避免账号/进度/题库/Key 分叉
5. **约定靠自觉，隔离靠机制**：不指望其它工具遵守 AGENTS.md，物理上分目录/分分支才可靠
