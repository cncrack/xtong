## 2. 关键决策

1. **新建批次默认停用**：`POST /api/plans` 的 `enabled` 缺省由 `True` 改 `False`；前端不改传值。`core/plans.create_plan` 的默认保持 `True` 不动（CLI/测试依赖其"启用即做冲突检查"语义）。对话框按钮文案由「创建并启用」改「创建（默认停用）」，hint 补一句。
2. **趋势图改横向条形**（用户拍板）：每天一行 = `日期 | 条 | "X 分 · N 视频"`，条长按当天分钟占比；天数多少都好读，不再出现"两根胖柱撑满屏"。摘要行保留峰值/合计/视频数。
3. **登录按钮弱化**（用户拍板）：已登录显示 `.ghost`（半透明灰）「🔑 会话」，tooltip 写明"仅会话失效时用"；未登录显示 `.primary`（强调色）「🔑 登录」。
4. **删除按钮加文字**：`🗑` → `🗑 删除`，降低误认成本。

## 5. 踩坑与风险

1. `_PAGE` 仍是 Python 非原始字符串 → JS 内**不得**写 `'\n'`（会被解码成真换行，整段脚本挂）。本次未触碰。
2. 面板启动入口是 `python -m xxt.cli panel`（**不是** `-m xxt.panel`，后者报 `No module named xxt.panel.__main__`）。
3. `create_plan` 默认 **不能**改成 `False`——`tests/test_plans.py` 依赖"默认启用→冲突检查"；只能改面板端点的缺省。
4. 已入库的旧批次 `enabled` 值不因本次改动而变（新建默认才改）。
