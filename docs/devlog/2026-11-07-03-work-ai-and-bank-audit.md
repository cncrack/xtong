## 二、逐项缺口

### D1. 🔴 AI 回填整条链路从未实跑

| 项 | 内容 |
|---|---|
| **事实** | devlog `2026-10-30-05` §5 第 1 条自陈：「测试用的是真实 DOM 结构与合成题干；**'服务端真的建卷 → 读题 → 点选 → 回读一致'整条链要等一次实跑**」 |
| **未验环节** | ① 服务端是否真能建卷（`showExam(id)` 触发）② `tm_arr` 真实字段是否与 `selectors.EXAM_TM_ARR_FIELDS` 一致 ③ 点选后页码面上是否真的选中 ④ 回读校验（脚本填完再读一遍比对）⑤ 交卷后判分能否入库 |
| **风险** | 合成 fixture 用的是**真实 DOM 结构**，但真实卷面可能多出字段/少字段、选项文本含 HTML 实体、题干带换行——这些只有实跑才知道 |
| **需要什么** | 一次人工：Chrome 在 9222 已登录 → 面板点某节「做练习」→ 看逐题表对不对 → 人工核对 → 人工点交卷 |

### D2. 🔴 题型只支持单选，其余 12 种一律拒填

| 项 | 内容 |
|---|---|
| **事实** | `config/settings.local.toml`：`allowed_types = "2"`；`work.py:155` 写着「题型未实测，停止回填」；`parse_tx_arr` 注释说页面共 **13 种**题型（含简答/论述/操作题） |
| **后果** | 若某节练习含多选/判断/填空，脚本**整卷拒填**（宁可停也不猜，这个保守是对的，但等于那节课做不了） |
| **要做的** | 逐个题型实测 → 通过一个就往 `allowed_types` 加一个（逗号分隔）。**多选/判断题优先级最高**（练习最常见） |
| **注意** | 主观题（简答/论述）走富文本写入，风险最高，建议**最后做且默认关** |
