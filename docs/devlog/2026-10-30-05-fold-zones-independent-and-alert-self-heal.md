# 2026-10-30-05 折叠区独立展开 + 告警自愈即时纠正（纠错即生效、日志留痕）

## 本次目标与结果

**目标**：处理用户面板实测反馈的三个问题——
1. 「其他」和「已学完」两个折叠区**联动**（点一个另一个也开/收，无法单独收回）；
2. 多账号卡片间折叠状态串味；
3. 旧代码把已学完课误判成 `structure` 存进 `run_logs` 后，横幅要**等零点**才消失——用户明确「错误纠正了就要马上有效果」「纠正要生效，但日志里面要体现」。

**结果**：✅ 三项全部落盘，全量 pytest **316 passed**（基线 314 + 本批新增 2）。

## 根因

- **问题 1&2**：上一批四分区（devlog-04）把两个折叠区**共用同一个 `EXPANDED[a.id]` 开关**（`toggleMore` 也按账号 id 记），导致「其他」「已学完」同开同收、不能独立收回。
- **问题 3**：面板 `_account_alerts` **优先信存量 `code`**（Q30 设计：怕拿人话文案二次归类归错）。守护当时用旧规则把「本地已无待学章节」写死成 `structure`（实证行 id=526，2026-10-30T12:50:35）。重启只换代码、**不回改历史行**；横幅查询又只读「今日」事件（`ts LIKE 今天%`），于是这条脏行一整天钉着横幅，到零点日期翻转才掉出——即用户看到的「重启没用、要等 0 点」。

## 关键决策与方案

- **折叠区**：每个区独立记展开状态——键改为 `${a.id}:r`（其他）/ `${a.id}:d`（已学完），`toggleMore(k)` 收字符串键；删除失效的共享 `const open`。键含账号 id → 天然账号隔离，不再跨卡串味。
- **告警自愈**（不改历史语义、只在读路径复核纠正）：面板出横幅前，对 `auto-suspend/auto-error/auto-hardstop` 且存量码**非** achieved 的行，剥离守护自加的标签词（`describe(raw_code)[0]`，如「页面打不开」）后按**当前规则** `classify` 复核；若复核为 achieved（典型 `done`）：
  - **即时纠正存量码**（`UPDATE run_logs SET code=? WHERE id=? AND code=?`，带 code 条件 → 幂等，命中才动）；
  - **记一条 `auto-corrected` 日志**（「旧记录原判『X』，按当前规则复核为『Y』，已纠正并不再告警｜原文…」）满足「日志里要体现」；
  - **本次不示警**（`continue`），横幅当场消失，不等跨天。
  - 只用于**消误报**（复核为 achieved 才动），真失败复核后仍是失败类不受影响。`EVNAME` 登记 `auto-corrected:'已纠正误报'`。
