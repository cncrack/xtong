## 三、第二批：AI 厂商配置系统

### 3.1 先说一个关键发现：gxks 库根本没有 `app_config` 表

规划时本想复用超星那套 provider 实现，先做了只读验证
（`data/debug/_verify_llm_key_store.py`，临时库）：

```
gxks 库里的表：gx_ops / gx_q_answers / gx_q_imports / gx_q_items /
              gx_q_paper_items / gx_q_papers / gx_q_parts / gx_q_types / meta
有 app_config 表吗： False
有 meta 表吗： True
```

而 `ai/llm.py::_load_key_from_db` 写死读 **`data/xxt.db` 的 `app_config`**。
⇒ **照抄超星那套 = "配置能存、但永远读不到 Key" 的假功能。**

同时验证了加密本身可用、且**密钥随 data_dir 隔离**：

| 验证 | 结果 |
|---|---|
| `master_key(data_dir)` → 加密 → 解密 | ✅ 还原 `'sk-test-123456'` |
| 用**另一个目录**的密钥解密 | ✅ 失败（`InvalidTag`）—— 安全设计，符合"数据封闭于自身 data/" |

### 3.2 新增 `src/xxt/ai/providers.py`（平台无关核心层）

- 内置 **9 家**主流厂商（DeepSeek / 智谱 GLM / 通义千问 / Kimi / MiniMax /
  文心一言 / 硅基流动 / OpenAI / Ollama 本地）
- `FIELDS`：**每个配置项都带中文说明**（厂商名 / 接口地址 / 模型 / API Key / 超时）
- 纯函数、无数据库、无平台细节 → 两个平台都能用，避免"各写一份必然走偏"

### 3.3 新增 `src/xxt/store/gxks_ai_config.py`（存取层）

- 厂商列表 / 当前选中 / 超时 → 存 gxks 库的 **`meta`** 表（键前缀 `ai.`）
- API Key → `core.crypto` 加密后存 `meta`，**只对外暴露 `has_key` 布尔**
- 空串 = **不修改**（面板不回显，无法区分"没填"和"清空"）

### 3.4 面板后端 `/api/ai*`（`panel_gxks/app.py`）

| 接口 | 作用 |
|---|---|
| `GET /api/ai` | 厂商列表 + 每项说明 + 当前选中 + `has_key` |
| `POST /api/ai/provider` | 新增/覆盖一家（按 name 判重） |
| `POST /api/ai/provider/delete` | 删除（只能删自定义的） |
| `POST /api/ai/current` | 切换当前厂商（只给名字也行，地址/模型自动补） |
| `POST /api/ai/key` | 保存 Key（加密）；留痕只记"已更新"，**绝不写 Key 内容** |

## 六、门禁（`scripts/push_check.py`）

第一次跑 **FAIL**，拦下 4 条，全部指向测试里的**假 Key 字面量**
（形如 `save_key(..., <key字面量>)` 的赋值写法命中了"疑似敏感赋值"规则）。

**门禁是对的**（宁可误拦）——即使值是假的，这种写法与真实泄露无法区分。

修的过程踩了一个坑：把测试改成运行时拼接后**门禁仍然拦**，
因为门禁扫的是 **`origin/main..HEAD` 的提交历史 diff**，旧提交里的字面量还在。
→ 用 `git commit --amend` 把修复并入那个未推送的提交，历史清干净后 **PASS**。

另：我新写的注释里带了完整的示例赋值也被拦（第 5 条），
说明**注释里的示例同样会触发**，已改成不带完整字面量的写法。
**同理，devlog 里也不能复述报错原文**——本段第一版就因为引用了原始报错行被拦，改写后才过。

## 八、关键决策及理由

1. **AI 配置存 gxks 自己的 `meta` 表，不复用超星 `app_config`** ——
   实测 gxks 库没有该表，照抄会得到"能存但读不到"的假功能。
2. **厂商列表收敛到 `xxt/ai/providers.py`** —— 超星面板那份是面板私有的，
   两边各写一份必然走偏（这个分支已经因为"各写一份"踩过探活的坑）。
3. **Key 只提交、不回显** —— 界面只有"已配置/未配置"，留痕只记"已更新"。
4. **新增/编辑改内嵌表单而非弹窗** —— 弹窗会遮住账号表，改的时候看不到对照。
5. **列宽显式给定、操作列图标化** —— 8 栏宽度放不下 9 列全称按钮。
6. **测试里的假 Key 用运行时拼接** —— 配合门禁，不让字面量进源码。
