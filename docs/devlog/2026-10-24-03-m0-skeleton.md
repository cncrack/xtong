## 关键决策及理由

1. **与 PLAN v0.2 对齐**：会话开始时发现 PLAN 已被另一会话升级到 v0.2（四阶段、弹题后置 P2、
   多账号 P1、Windows/Docker 双形态）。本会话所有产出按 v0.2 执行：配置新增 `[quiz]`
   段（`enabled=false` 默认关，P0/P1 不碰弹题）；`[learn]` 只留视频学习策略。
2. **登录成功判定用 `uid` cookie**：学习通登录成功后在 .chaoxing.com 域写入 uid cookie，
   轮询 `context.cookies()` 比盯 URL 跳转更稳（不依赖登录后的重定向路径）。
3. **登录入口用 passport2 通用页（`passport2.chaoxing.com/login`）**：用户确认账号密码直登
   （非学校 SSO），该入口即账密/扫码通用页；`xxt login` 为有头浏览器人工输入（P0 首版最稳），
   **账号密码代填与自动重登（凭据加密入库）留到 M1 后半段**。
4. **会话探测用 URL 重定向启发式**（未登录访问 i.chaoxing.com 会跳 passport 登录页），
   代码中已标注：实况验证时若发现更优信号（如页面用户名元素）再修正。
5. **Playwright 延迟导入**（cli 内局部 import）：`xxt init` 不依赖浏览器内核即可运行。
6. **选择器集中放 `adapters/chaoxing/selectors.py` 且显著标注"未实况核对"**：初始选择器是
   猜测值，防止后续会话误当作已验证。
7. 测试断言用"包含必须表"而非相等：`AUTOINCREMENT` 会附带生成 `sqlite_sequence` 表。
8. git 只 init 不 commit：遵守"用户未要求不提交"约定。
