# 2026-11-06-08 浏览器卡片按钮重排（文案不再被截断）

## 一、用户诉求

> 截图：卡片里「启动并登录 / 停止 / 复制命令 / 已配密码」挤在一行，
> 「批量 / 全选待启动 / 未选中 / 批量启动浏览器 / 一键启动并学习 / 批量停止」挤成更窄的一行，
> 好几个按钮已被省略号截断。原话：「这些按钮优化一下布局吧」。

## 二、问题定量（为什么非改不可）

侧栏宽度 = 主区 8fr / 侧栏 4fr 里的后者，**约 350px，减内边距后约 320px**。

原布局每组是「**42px 标签** + 按钮 `flex:1 1 0` 均分」：

| 组 | 元素数 | 每个按钮宽 | 最长文案需要 | 结果 |
|---|---|---|---|---|
| 浏览器 | 3 按钮 + 标签 | ≈ 90px | 「启动并登录」≈ 62px | 勉强 |
| 会话 | 3 按钮 + 标签 | ≈ 90px | 「重新登录」≈ 50px | 勉强 |
| 批量 | 4 元素 + 标签 | ≈ 65px | 「一键启动并学习」≈ 88px | **必截断** |

批量行最惨：4 个元素挤在 320px 里，每个只剩 ~65px，而「一键启动并学习」要 88px
→ 就是用户截图里那个「一键启动并…」。

还有第二个问题：**主次不分**。「启动并登录」是主操作、批量是次级批量操作，
却因为宽度一致而长得一样。

## 三、改法（三层）

1. **组标题独占整行**（`.bgrp-title`，`flex:1 1 100%`）
   把原来固定的 42px 标签竖着挪到按钮上方一行小字 ——
   每行按钮的可用宽度从 `320-42-6=272px` 变成 `320px`，**多出 15%**。

2. **按钮两列网格**（`.bgrp-btn` 从 `flex:1 1 0` 改成 `flex:1 1 44%`）
   - 两列：每列 ≈ (320-6)/2 = **157px**，长的 182px（视口大时）；
   - 奇数个时最后一个自动**占满整行**（flex 换行的天然行为）；
   - 关键前提是 `min-width:0` —— flex 里不写它，按钮会按内容撑宽、撑破容器，
     反而出不了省略号（这是老代码里已经踩过的点）。

3. **主次分级**（`.bgrp-btn--sub`）
   - 「启动并登录」保留 `primary`（实心主色）；
   - 「停止」保留 `danger`（红色）；
   - 批量组里只有「一键启动并学习」是 `primary`（它才是批量最该点的），
     其余（全选待启动 / 只启动浏览器 / 批量停止）用 `bgrp-btn--sub`（细边、常规字色）。

4. **文案顺手瘦身**（缩短 1~2 个字，含义靠 `title` 补）
   - 批量组标题：「批量」→「**批量（多账号）**」（说清它作用于多个账号）
   - 「批量启动浏览器」→「**只启动浏览器**」（与「一键启动并学习」区分开：
     前者只起浏览器、后者还自动开始学习）
   - 「复制命令」从 `mini` 改成 `bgrp-btn bgrp-btn--sub`（与其他按钮同宽，不再突兀）

5. **窄屏**（≤760px）：`flex:1 1 100%` 一列一个 + `min-height:38px`
   —— 按 AGENTS 界面约定②（窄屏换行）与④（手指可点）。

### 布局效果（推算，见 `data/debug/diag_btn_fit.py`）

| 视口 | 侧栏内容宽 | 每列宽 | 最长文案需要 | 结论 |
|---|---|---|---|---|
| 1280 | 371px | **182px** | 88px | OK |
| 1440 | 424px | 209px | 88px | OK |
| 1920 | 584px | 289px | 88px | OK |

改前每列 ≈ 90px，**改后 182px，翻倍**。

## 六、过程中的自身失误（记下来防再犯）

这次改 CSS 时，**连续三次把中文段落写坏**：`flex:1 ination 100%`、
`flex: coinc 0 0`、`titleimy=`、`会话 ouk 3 个`，还留下一段重复的旧 `@media` 块和
一段重复的 `<div id="browser">`。

根因是：**一次 edit 里塞了太多行、且 `old_string` 猜了空格**，
匹配失败后我改用「按行号切片重写」，但重写内容本身又被编码弄坏。

有效做法（本次最终采用）：
1. 先 `read` 拿到**真实原文**（带行号），不再凭记忆拼 `old_string`；
2. 替换后**立刻用 Python 逐项断言**（`replacement chars` / 已知坏串计数 /
   关键类名计数 / 重复容器计数）；
3. 用「锚点找块 + 按行号切片」而不是模糊字符串匹配。

已写进本 devlog，下次改 HTML/CSS 直接照这三步。
