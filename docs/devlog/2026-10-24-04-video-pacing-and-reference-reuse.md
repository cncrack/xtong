# 会话记录 2026-10-24-04 — 视频拟人化方案与参考项目复用分析（方案 v0.4）

> 注：本会话与 M0 骨架会话（devlog 03）并行，devlog 序号调整为 04；
> v0.3 已被"M0 骨架完成"记录占用，本次变更登记为 **v0.4**。

## 本次目标

1. 用户需求：看视频时自动切下一节、**模拟人的行为**（有时停顿有时不停）、**不要频繁登录**以防封号，要求给方案；
2. 用户提供参考项目 https://github.com/chaolucky18/ 要求分析可复用/可加强重构之处；
3. 用户确认后回写 `docs/PLAN.md`。

## 调研结论（xuexitongScript，约 2k star，2026-10-23 仍活跃）

- 形态：**油猴/控制台注入课程播放页的 JS**，页内 DOM 自动化；等 `#coursetree` 出现 → 嵌套 iframe（`iframe.ans-insertvideo-online`，深度≤2）内找 `video#video_html5_api` → 1.5x 播放（静音降级）→ 每秒巡检（恢复暂停/卡进度 7s 看门狗/ended 后点章节树下一节 `.posCatalog_name`）；
- 处理了"学习目标→'2视频'页签（`.prev_white`）"、"章节测验→`#prevNextFocusNext` 跳过"、防失焦/鼠标移出暂停；
- **没有**：登录、多账号、持久化、答题、拟人化（全是固定延时、固定 1.5x）。

## 结果

✅ 完成。方案升级 v0.4，核心变化：

1. **执行架构定为混合模式**：外层 Playwright 编排决策 + 页内注入 watcher 细粒度执行，事件桥（postMessage/exposeFunction）通信；watcher 以 v3 脚本为底本重构；
2. **上报-决策模式**：页内只上报事件（playing/ended/stalled/…），切节时机由外层按随机节奏决定——这是拟人化的挂点，替换其固定 1s/3s 延时；
3. **拟人化参数化**：切节间隔分布（70% 3~15s 连看 / 20% 30~90s 短歇 / 10% 3~10min 离开）+ 专注会话（25~60min 学 + 5~15min 歇）+ 每日窗口（默认 08:00–23:00）与时长上限；所有节奏为配置区间，代码禁止固定 sleep；
4. **登录防封三招**：storage_state 滚动续期（每次运行结束回写最新 cookie）+ 登录预算制（24h ≤1~2 次，失败即冷却转人工）+ 长会话模式；探测不碰登录页；
5. **不采纳参考项目默认 1.5x**：默认 1.0~1.25x 随机（完成时长异常短是机器特征）；
6. **复用边界**：选择器与保活思路直接复用；watcher 按我们的协议自行重写（上游 License 不明确，避免直接抄代码）。
