## 二、推送过程（两个环境坑，已入档）

   解决：设 `required_permissions=all` 在沙箱外执行——这与 STATUS §3 已记的「面板必须沙箱外起」同源，
   **凡是 git 写操作（push/commit 涉及锁文件）都别在沙箱里跑**。
2. **PowerShell 把 git 的进度输出报成 `NativeCommandError` + exit 1**：真实结果是成功的。
   判成败**只看** `git rev-list --count origin/main..HEAD`（本次由 2 → 0），不看退出码、不看红字。
